# Claude 睡前故事合集

用故事讲一个真知识。每篇都不长——故事三百到六百字，解释三五百字，最后一张三行的"小本本"卡片，让读完的人能带走一句话。

不是哄睡的那种。目标是让人愿意多醒两分钟，而这两分钟里得有一个"哦，原来是这样"。

## 系列

- **空气的两次冤案** —— 05、06。1854 年空气被冤枉（凶手是水），1952 年空气是真凶却被开脱。两次判错方向相反。
- **更快是错的问题** —— 03、04。真起作用的不是"更快"，是改变相对关系或流程结构。

## 用法

想在自己的 Claude Code 里用这套流程，把 [`skill/SKILL.md`](skill/SKILL.md) 放进你的 `~/.claude/skills/` 下建一个目录：

```
~/.claude/skills/story-time/SKILL.md
```

然后说「来点故事」就行。技能里写了完整的写作规矩：故事在前、必须有一下反转、承重的数字不许为文采让位、讲完给三行小本本卡。

默认**不自动存**——它会先问要不要存、存到哪。

## 内容说明

- 每篇的科普部分都核过来源，具体数据写在正文的小本本卡里
- 第 05 篇是英文的，按 A2 难度写，生词带中文夹注
- 第 07 篇是日语的，按 A1 难度写，每段配中文梗概
- 第 01 篇是纯虚构，唯一一篇没有知识点的
